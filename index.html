Data & backups

Your data is stored in this browser unless you configure a cloud backend.

Local storage
This standalone version saves data on this device/browser using localStorage. It does not sync between devices and is not protected by an online login. Export backups regularly and avoid using it on a shared computer for sensitive records.

Cloud sync and security

For safe access across your phone and computer.

Backend required

A cloud version needs an authentication service and database, such as Supabase Auth + PostgreSQL with Row Level Security (RLS). The database must enforce owner-only access on every business, transaction, investment, and goal record. Never put a service-role key in frontend code. Configure automated database backups and test restoration before relying on i7 for important financial records.

This file does not pretend to provide cloud synchronization, authentication, bank connections, or automated online backups.

Danger zone

Destructive actions cannot be undone without a backup.
